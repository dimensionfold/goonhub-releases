# Goonhub releases

Signed Android APKs and self-update metadata for Goonhub, a Compose
Multiplatform media aggregator for Android TV, Android phones, and Windows.

Download a stable APK from **Releases**. Choose **cast** for Google Cast support
or **foss** for the build without Google Play Services. Updates preserve your
installed flavor and require confirmation before download and installation.

Every release includes `update.json`, SHA-256 hashes in that metadata, and a
matching `goonhub-<version>-source.tar.gz` archive containing corresponding
source and build instructions. Goonhub is AGPL-3.0; Orion Store-derived portions
remain GPL-3.0. Both licenses and attribution accompany the source archive.

Public APKs contain no personal seed backup or private provider/telemetry keys.
Development history is maintained separately. Temporary `incoming/*` branches
are publication staging; use published stable releases for installation.
